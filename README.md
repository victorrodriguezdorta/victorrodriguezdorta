## 🎮 PALINKO

### Real-time multiplayer web application powered by AI

PALINKO is a real-time multiplayer word game where players compete by connecting words according to hidden semantic relationships.

The backend was designed using **Java, Spring Boot and Hexagonal Architecture**, with WebSockets for real-time communication and an LLM for semantic evaluation.

**Tech Stack**

**Key features**

* ⚡ Real-time multiplayer communication with **WebSocket / STOMP**
* 🔐 Authentication with **Spring Security, JWT and BCrypt**
* 🗄️ PostgreSQL persistence using **Spring Data JPA**
* 🤖 LLM integration for semantic evaluation
* 🏗️ Hexagonal architecture
* 🧪 Unit testing with **JUnit & Mockito**
* 🐳 Docker containerization

## ♻️ RouteWaste

<div align="center">

<img src="./routewaste.svg" width="850" alt="RouteWaste">

</div>

### Waste collection route planning and optimization platform

Final Degree Project focused on the **planning and optimization of waste collection routes using IoT data**.

The system combines a Java/Spring Boot backend with a Vue frontend and an optimization algorithm capable of generating collection routes based on container capacity, distance and estimated fill levels.

🏆 **Final Degree Project — Grade: 10/10 · Proposed for Honors**

**Tech Stack**

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square\&logo=openjdk\&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-6DB33F?style=flat-square\&logo=springboot\&logoColor=white)
![Vue](https://img.shields.io/badge/Vue_3-4FC08D?style=flat-square\&logo=vuedotjs\&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square\&logo=typescript\&logoColor=white)
![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat-square\&logo=mongodb\&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square\&logo=docker\&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat-square\&logo=githubactions\&logoColor=white)

**Key features**

* 🗺️ REST APIs for vehicles, containers and collection facilities
* 🧠 Greedy optimization algorithm for route generation
* 📊 Route calculation based on distance and container capacity
* 🐳 Isolated execution of optimization algorithms using Docker
* 🏗️ Hexagonal architecture
* 🔄 CI/CD with GitHub Actions
* 🧪 Unit tests with **JUnit**
* 🎭 End-to-end testing with **Playwright**
* 🌐 Vue 3 + TypeScript frontend
